# Engineer's Carnival 2026

Official website for **Engineer's Carnival 2026**, a student-led engineering carnival organised by **The Explorer Club, Parul Institute of Technology, Parul University**.

The carnival brings together technology, creativity, innovation, and competition through a diverse range of student competitions and activities.

---

## About the Event

**Engineer's Carnival 2026** is a one-day engineering festival designed to give students a platform to compete, create, collaborate, and showcase their skills.

### Event Details

- **Event:** Engineer's Carnival 2026

- **Date:** 18 September 2026

- **Venue:** Parul Institute of Technology, Parul University

- **Location:** Vadodara, Gujarat, India

- **Organised by:** The Explorer Club

- **Format:** One-Day Engineering Carnival

---

## Competitions

The website features eight competition arenas:

1. **Traitor**

2. **Robo Fight**

3. **Battle Royale**

4. **Cook-Off**

5. **ClueChase**

6. **CodeCraft**

7. **Frame & Focus**

8. **Pixel Play**

Each competition has its own dedicated page containing its overview, rules, requirements, and registration options.

## Website Features

- Responsive design for desktop, tablet, and mobile

- Competition directory

- Individual competition detail pages

- Online registration links

- Event schedule

- General event rules

- Prize and recognition information

- Contact and support information

- Dark futuristic engineering-inspired interface

- SEO metadata for major pages

## Tech Stack

This project is built using:

- **Next.js**

- **React**

- **TypeScript**

- **Tailwind CSS**

- **Framer Motion**

- **Next Font**

- **Google Forms** for competition registrations

### Fonts

The website uses:

- **Syne** — Display headings

- **DM Sans** — Body text

- **IBM Plex Mono** — Technical labels and interface elements
